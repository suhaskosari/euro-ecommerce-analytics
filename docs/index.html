02Anomaly detection

STL seasonal decomposition of daily order counts, flagged with a Poisson residual test (|z| > 3.5).
Daily net revenue, flagged days highlighted
Drop
Spike

Flags use an STL seasonal decomposition of daily order counts with a Poisson residual test (|z| > 3.5). On the injected incidents it catches all 5 ground-truth days at 50% precision, versus 7% for the original weekday-median detector. See outputs/anomaly_eval.md for the full threshold sweep and its caveats.
